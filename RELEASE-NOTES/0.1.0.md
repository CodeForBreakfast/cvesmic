This is the first release of CVEsmic, a Dux Shell plugin that shakes the screen when a new vulnerability appears.

It polls the pwn.watch feed and shakes a frozen picture of the screen when an item with an unseen id arrives. The item's severity sets how hard and how long it shakes.

It works on any compositor the shell supports, not only niri.

The shake never shows over a lock screen or to a screen cast. On niri it waits until no cast is running, read from the shell's own niri service.

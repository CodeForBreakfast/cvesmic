CVEsmic now runs on every desktop it supports, and each release carries a package for each one.

On GNOME, CVEsmic is a GNOME Shell extension, for GNOME Shell 48, 49 and 50 under Wayland. It moves the desktop itself, so your apps keep running as it shakes, and it takes no picture of the screen.

On KDE Plasma, a KWin effect does the shaking, and the Quickshell build watches the feed. CVEsmic loads the effect when it needs it.

Anywhere else, CVEsmic runs on Quickshell alone, as well as inside Dux Modular Shell, which used to be called DankMaterialShell.

When the shaking stops, the news follows. A notification names each new item and its severity, and a click on it opens the item on pwn.watch. One poll notifies about five items at most.

Every release attaches `cvesmic-quickshell.tar.gz`, `cvesmic-kwin.tar.gz`, the GNOME extension zip and a `SHA256SUMS` file to check them against. The README says how to install each one.

CVEsmic is licensed under the MIT licence, and SECURITY.md says how to report a vulnerability privately.

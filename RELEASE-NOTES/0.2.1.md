This release readies the GNOME extension for review on extensions.gnome.org. Nothing changes for the Quickshell or KDE Plasma builds.

The GNOME extension no longer writes each poll's result to the log. It disconnects every handler it connected when you turn it off, and it now lists GNOME Shell 51 as supported.

The extension zip carries the release's version in its metadata, so the listing shows the same number as the release.

# Security policy

## Reporting a vulnerability

Please report a vulnerability in CVEsmic privately. Do not open a public issue or pull request for it.

1. Open the [Security tab](https://github.com/CodeForBreakfast/cvesmic/security) of the repository.
2. Choose **Report a vulnerability**.
3. Describe what you found, how to reproduce it, and which version or commit you tested.

Only the maintainers can see the report. We will reply, work with you on a fix, and credit you in the release notes if you wish.

CVEsmic is a small project, so please allow a few days for a first reply.

## Scope

This policy covers the code in this repository. A weakness in the pwn.watch feed, in the shell, or in the compositor belongs with the project that owns it.
